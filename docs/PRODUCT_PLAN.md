# SsCalendar — Commercial v1.0 Product Plan

> **갱신일:** 2026-10-11
> **프로젝트:** `SsCalendar` / 제품명 `S's calendaR`
> **문서 역할:** 제품의 목표·현재 제공 범위·출시 전 판단 기준을 정리한다. 개발 경과, 실패한 수정 시도, 재현 증거 및 Git 복구 이력의 상세 원문은 [`DEVELOPMENT_STATUS.md`](./DEVELOPMENT_STATUS.md)를 기준으로 한다.
> **최신 사용자 확인 코드 기준:** `fa68773` (`feat: make external calendar events read-only`). 문서 추가·수정 이후의 Git 상태까지 확인했다는 뜻은 아니다.

## 1. 제품 정의와 원칙

**핵심 제품 정의**

> 월간 일정을 한눈에 보기 편하고, 빠르고 깔끔하게 일정을 관리할 수 있는 iPhone 네이티브 캘린더.

- 플랫폼: iPhone / iOS. iPad 지원은 후속 검토 대상이다.
- 앱 본연의 범위는 **달력 보기 + 일정 관리**다.
- AI, 일기, 습관, SNS 등으로 범위를 넓히지 않는다.
- **새 기능보다 기존 기능의 안정성과 가독성을 우선**한다.
- 자체 일정 데이터는 SwiftData를 통해 기기에 저장한다. SsCalendar 자체 로그인·서버·클라우드 동기화는 제공하지 않는다.
- 시스템 캘린더의 iCloud·Google 등 동기화는 해당 계정과 iOS의 기능이며, SsCalendar 자체 데이터의 동기화를 의미하지 않는다.

## 2. 현재 제품 상태 — 2026-10-11

**상용 v1.0 출시 준비 단계.** 기능 구현과 주요 실기기 검증은 진행됐지만, **App Store 등록·출시 및 실제 유료 판매 완료는 확인되지 않았다.**

### 구현 및 사용 검증 이력이 있는 기능

| 구분 | 기능 및 상태 |
| --- | --- |
| 달력 보기 | 월간 달력, 4/5/6주 자동 구성, 날짜 선택, 오늘 이동, 이전·다음 달, 연간 달력 및 이동 기능 |
| 자체 일정 | 신규 작성, 조회, 수정, 삭제, 종일·시간·여러 날 일정, 색상, 제목·메모 |
| 반복 및 알림 | 반복 일정, 개별 발생분 수정·삭제 예외 처리, 로컬 알림 |
| 위젯 | 홈 화면 월간 위젯, 잠금화면 Today/Next 위젯, D-Day 관련 홈/잠금화면 위젯 |
| D-Day | **자체 일정** D-Day ON/OFF, 편집 중 미리보기, 관련 위젯 표시 |
| 공휴일·언어 | 한국어·영어 관련 현지화, 한국·미국 공휴일 관련 기능, 음력 표시 |
| 테마·공유 | 라이트/다크/시스템 테마, App Group 기반 앱·위젯 데이터 공유 |
| 외부 일정 | EventKit을 통한 외부 일정 조회 및 앱·위젯 표시 — **읽기 전용** |

위 목록은 이전 작업 보고와 사용자 확인에 근거한다. 각 언어·국가·기기 조합의 모든 세부 동작이 최종 출시 QA를 통과했다는 의미는 아니다.

### 최신 품질 검증 결과

- 기준 코드: `fa68773`, `main`에 푸시 완료(사용자 확인).
- Codex 보고: 앱·위젯 빌드 성공, 자동 테스트 **110/110 통과**.
- 실제 iPhone 확인 완료: 외부 일정 앱·위젯 표시, 외부 상세 진입 차단, 새 일정 로컬 저장, 자체 일정 수정·삭제·D-Day 및 D-Day 위젯 정상.
- 위 네 항목 외의 App Store 출시 수준 전체 QA는 별도로 남아 있다.

## 3. 외부 시스템 캘린더 정책 — 현행 확정 범위

**v1.0 현재 기준: 외부 일정은 앱·위젯에서 볼 수 있지만 SsCalendar 안에서 열거나 편집할 수 없다.**

| 사용자 동작 | 현재 제공 |
| --- | --- |
| iOS 시스템 캘린더 연동 설정 및 외부 일정 불러오기 | 제공 |
| 외부 일정의 월간·일간 화면 표시 | 제공 |
| 외부 일정의 홈·잠금화면 위젯 표시 | 제공 |
| 외부 일정 탭으로 세부사항 열기 | **차단** |
| 외부 일정 수정·삭제 | **차단** |
| 외부 일정에 D-Day 설정 | **차단** |
| 새 일정을 외부 캘린더에 저장 | **선택 UI 숨김; 신규 일정은 SsCalendar 자체 저장** |
| SsCalendar 자체 일정 작성·수정·삭제 및 D-Day | 제공 |

- 현재 코드에 `SystemCalendarService.isExternalEventAccessEnabled = false` 기능 플래그가 적용되어 있다는 구현 보고가 있다.
- 기존 EventKit 상세·편집·삭제 및 외부 저장 구현은 **삭제하지 않고 보존**했다. 사용자가 진입하는 경로만 임시 비활성화한 상태다.
- 기존 외부 캘린더 기본 저장 위치 설정값은 불필요하게 지우지 않는다.
- **향후 편집 기능 재개는 별도 판단**이며, 플래그 전환만으로 모든 흐름의 복구가 보장되지는 않는다.
- 외부 일정을 표시하는 것과 외부 일정을 수정·삭제할 수 있는 것은 다른 기능이다. 타사 캘린더와 비교할 때도 구분해서 검토한다.

### 읽기 전용 전환 배경 — 미해결 문제

1. SsCalendar 안에서 Apple 제공 외부 일정 편집 화면에 한글을 입력하면 조합이 깨지는 현상(예: `광장`, `고기`). 동일 외부 일정을 **iPhone 기본 캘린더 앱에서는 정상 입력**하는 비교 결과가 있다.
2. 외부 일정 상세 화면에서 삭제 버튼이 잠깐 중복·깜빡이는 현상.
3. 상세 화면을 생략하고 Apple 편집 화면을 직접 띄우는 방식은 중복 버튼을 피했지만, **삭제 후 편집 화면이 멈추는 새로운 문제** 때문에 채택하지 않았다.

두 문제 모두 **근본 원인 미확정**이다. 읽기 전용 전환은 해결이 아니라 출시 범위를 안전하게 제한한 조치다. 실패한 실험 내용은 `DEVELOPMENT_STATUS.md`에 기록했다.

## 4. D-Day 제품 정책

- **SsCalendar 자체 일정에서만** D-Day를 설정·편집할 수 있다.
- 일정 편집 화면에 D-Day ON/OFF와 해당 날짜 기준 미리보기를 제공한다.
- 기존 D-Day 홈/잠금화면 위젯을 유지한다.
- 지난 일정의 표시·제외, 반복 일정 처리 등 **이미 구현된 규칙은 임의로 변경하지 않는다**.
- 외부 일정에는 D-Day 설정을 제공하지 않으며, 외부 상세 진입을 우회하는 D-Day 메뉴도 차단한다.

## 5. 상용화 목표와 판매 방향

**목표:** App Store에서 일회 구매 방식으로 판매 가능한 Commercial v1.0을 출시하고, 실제 사용자 피드백을 받아 업데이트한다.

| 항목 | 현재 방향 | 확정 여부 |
| --- | --- | --- |
| 기준 시장 | 미국 | 기존 기획 방향 유지 |
| 동시 판매 후보 | 미국·한국·인도네시아 | 후보, 출시 전 결정 |
| 판매 방식 | 구독보다 일회 구매 우선 | 검토 방향 |
| 기준 가격 | **US$4.99** | **미확정 후보**. 출시 전에 재평가 |
| iPad 등 플랫폼 확대 | iPhone 이후 검토 | v1.0 필수 아님 |

기능 완성, App Store 심사 통과, 매출 확보는 별개의 검증 단계다. 예상 개발 기간이나 판매 성과를 확정적으로 기재하지 않는다.

## 6. 언어·지역·공휴일 원칙

- **Language**와 **Region & Holidays**는 개념적으로 분리한다. 언어 변경이 곧바로 공휴일 지역 변경을 의미해서는 안 된다.
- 한국어·영어 및 한국·미국 공휴일 관련 개발 이력은 있다. 출시 대상별 표현과 날짜·공휴일 정확성은 최종 QA에서 확인한다.
- Bahasa Indonesia와 인도네시아 공휴일은 **기존 확장 후보**이며, 현재 구현 완료로 간주하지 않는다.
- 국가/언어 선택의 기본값·추천·독립 변경 UX는 출시 전 현재 코드와 기획을 대조해 확인한다.
- Apple 제공 EventKitUI의 언어가 앱 설정 언어와 다르게 표시되던 문제는 과거에 확인됐으나, 현재 외부 편집 화면이 비활성화되어 사용자에게 노출되지 않는다.

## 7. v1.0 기능 범위 판단

### 이미 진행된 핵심 개발

기존 계획의 두 핵심 신규 기능은 더 이상 미착수 작업으로 취급하지 않는다.

- **Lock Screen Today/Next Widget:** 개발·검증 이력 있음. 정확한 실시간 변경을 약속하지 않으며 WidgetKit 갱신 제약을 고려한다.
- **Adaptive Event Title:** 월간 일정 제목 가독성 개선 작업 이력 있음. 긴 영어 제목·좁은 셀·일정 밀집도별 추가 다듬기는 출시 전 실기기 QA에서 필요성을 판단한다.

이후 추가된 연간 달력, 반복 일정 예외 처리, D-Day 및 D-Day 위젯도 현재 제품 범위에 포함한다.

### v1.0에서 범위 확대 금지

- AI 상담·요약, 일기·습관 관리, 복잡한 To-do, SNS·커뮤니티.
- 생활계획표의 자동 일정 재계산·재계획 시스템.
- 미검증 외부 일정 쓰기 기능의 성급한 재활성화.
- 핵심 사용 경험에 직접 기여하지 않는 신규 기능 확장.

새 아이디어는 원칙적으로 v1.1+ 후보로 기록하되, 출시 결함 수정은 예외로 한다.

## 9. 출시 전 작업 순서

1. **현행 기능·범위 동결:** 외부 일정은 읽기 전용, 자체 일정 기능은 유지한다.
2. **실기기 회귀 QA:** 자체 일정 작성/수정/삭제, 반복·예외·알림, D-Day, 월간·연간 이동, 앱·위젯 외부 일정 표시를 점검한다.
3. **언어·지역 QA:** 한국어·영어, 날짜 형식, 한국·미국 공휴일, 긴 제목 및 텍스트 잘림을 점검한다.
4. **위젯/권한 QA:** 잠금화면·홈 화면 위젯, 권한 거부·해제, 재실행 후 데이터 유지 및 관련 안내 문구를 확인한다.
5. **상품 정책 최종 확정:** 출시 국가, 언어 지원 범위, 가격, 일회 구매 여부, 스토어 설명·이미지 등을 확정한다.
6. **App Store 제출 준비:** 실제 앱 권한 설명, 개인정보 처리 안내 및 스토어 제출 요구사항을 점검한다.
7. **출시 → 피드백 → 첫 업데이트:** 출시와 매출·사용자 피드백은 실제 결과로 판단한다.

이 순서는 작업 지침이며, 위 항목이 모두 완료됐다는 의미가 아니다.

## 10. 개발·문서 관리 원칙

- 사용자가 확인한 최신 **코드 기준 커밋은 `fa68773`**. 근거 없이 이전 실험 코드를 복원하지 않는다.
- 기존 기능을 바꿀 때 앱, 위젯, SwiftData, App Group, 반복 일정·알림·D-Day에 대한 영향부터 확인한다.
- **자동 테스트 통과와 실기기 UI/IME 검증을 구분**한다.
- Git 명령은 사용자가 직접 실행한다. Codex·Claude 등 에이전트에는 조회를 포함한 모든 Git 명령 실행을 금지한다.
- `SsCalendarWidgetExtension.entitlements`는 위젯 `CODE_SIGN_ENTITLEMENTS`에 연결되어 있으며 앱·위젯 모두 `group.sscalendar`를 사용한다는 점검 결과가 있다. **삭제하지 않는다.**
- 본 문서는 제품 정책과 범위의 기준이며, 기술적 문제의 상세 분석과 실패 시도 기록은 [`docs/DEVELOPMENT_STATUS.md`](./DEVELOPMENT_STATUS.md)에 둔다.
- 본 문서를 갱신할 때 구현 완료, 실기기 검증 완료, 검토 중, 보류, 실패를 혼동하지 않는다.
